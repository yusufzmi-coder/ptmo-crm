# PTMO CRM documentation

Dokumen dalam folder ini bergerak bersama projek `ptmo-crm`.

| Folder atau fail | Kegunaan |
| --- | --- |
| `zones.md` | Reka bentuk multi-zone semasa. |
| `open-findings.md` | Penemuan dan perkara yang masih perlu disahkan. |
| `plans/legacy/` | Pelan awal untuk rujukan; bukan spesifikasi semasa. |
| `references/` | Link dan rujukan luar yang berkaitan dengan projek. |
| `working-notes/` | Nota kerja dan konteks terdahulu. |

Skrip SQL ujian atau kerja sementara kekal dalam `_scratch/` dan tidak patut dianggap dokumentasi rasmi.
