# Topik: PTMO CRM — akses multi-zone HQ

Folder ni untuk SATU topik perbualan. Slug: `ptmo-crm`.

## Arahan tetap untuk Claude

1. **Baca `NOTES.md` dahulu** sebelum jawab apa-apa. Di situ keadaan terkini topik ni.
2. **Bila ada keputusan dibuat, arah bertukar, atau soalan terbuka baru — kemas kini
   `NOTES.md` terus.** Jangan tunggu disuruh. Tulis keputusan dan sebabnya, bukan
   transkrip perbualan.
3. **Link, artifact, riset, dokumen → masuk `REFS.md`.** Satu baris satu link,
   dengan satu ayat kenapa ia penting.
4. Plan dari `~/.claude/plans/` yang berkaitan topik ni → salin masuk `plans/`.
5. `sesi/` diuruskan automatik oleh hook. **Jangan sentuh.**
6. Nama fail ikut `ucop-vault/memory/file-naming.md`: huruf kecil, sengkang,
   fail bertarikh mula dengan `YYYY-MM-DD-`.

## Konteks

Yusuf bercakap BM (aku/kau). Jadi sparring partner, bukan yes-man — cari lubang dalam
idea dia dahulu, baru bantu laksana. Jawapan dulu, huraian kemudian.

Backup: folder ni auto-mirror ke Google Drive (`ucop-vault/projects/ptmo-crm/`) setiap kali
sesi tamat. Drive destinasi backup sahaja — **jangan edit dari telefon**, ia akan ditimpa.
